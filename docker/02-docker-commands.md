**Basics Docker Commands**



* *docker run nginx* = Run container
* *docker ps* = shows  running containers
* *docker ps -a* = showing all containers
* *docker stop container\_name* = Stops a running container
* *docker rm container\_name* = Remove container
* *docker images* = shows  images
* *docker rmi nginx* = deletes an image
* *docker pull nginx* = downloads image without running it
* *docker run ubuntu* = starts and immediately stops because Ubuntu has no running process

&#x20;    docker run ubuntu sleep 5 = keep it running for 5 seconds

* *docker exec container\_name command* = Run  command inside  container
* *docker run -d kodekloud/simple-webapp* = runs in background
* *docker attach container\_id* = Connects  to  container
