**Dockers Basics**



**What is Docker?**

Docker is a tool used to run applications inside containers.

It makes applications work the same on every computer.



**Why Docker is Needed?**

* Runs each application in a separate container.
* Each container has its own dependencies.
* Applications don't interfere with each other.
* Same application works on any system with Docker installed.



**Docker images=** Template/package of an application

**Docker Container**= Running instance of an image
