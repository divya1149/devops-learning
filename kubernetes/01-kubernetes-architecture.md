###### **Kubernetes Architecture**

1. Node = Machine where Kubernetes is installed, runs containers/applications
2. Cluster = group of multiple notes, if one node fails, applications continue running on other nodes
3. Master Node = control and manages the entire cluster
4. API Server = Front-end of Kubernetes, receives all commands from users
5. etcd =database of Kubernetes
6. Controller = Problem Solver, Restarts failed containers
7. Kubelet = Node Manager
8. Container Runtime = Software that actually runs containers



**Components Locations**

**1 Master Node**

Contains:

* API Server
* etcd
* Scheduler
* Controller



**2 Worker Node**

Contains:

* Kubelet
* Container Runtime





###### **kubectl**

* Command-line tool used to manage Kubernetes
* *kubectl run hello-minikube* = deploy application
* *kubectl cluster-info* = cluster information
* *kubectl get nodes =* list nodes
