Flask + MySQL App with Docker Compose 🐳



&#x20;What is this project?

A Python Flask web app connected to a MySQL database,

running together using Docker Compose.



&#x20;What I learned

\- How to use Docker Compose

\- How to connect two containers together

\- How to use environment variables in Docker

\- How Docker volumes save data permanently



Technologies Used

\- Python

\- Flask

\- MySQL

\- Docker

\- Docker Compose



&#x20;Project Structure

flask-mysql-app/

├── app.py

├── Dockerfile

├── docker-compose.yml

└── requirements.txt



&#x20;How to run this project

Step 1 - Clone the repo

git clone git@github.com:divya1149/devops-learning.git



Step 2 - Go to project folder

cd devops-learning/projects/flask-mysql-app



Step 3 - Start the app

docker compose up



Step 4 - Open in browser

http://localhost:5000

http://localhost:5000/test-db
